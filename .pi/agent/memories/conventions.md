# 项目约定

> 跨项目的通用约定，pi 必须始终遵守。

## 安全
- 绝不 hardcode API key / token，必须用环境变量或配置文件
- 所有用户输入在边界处验证，不信任任何外部数据
- 错误信息不暴露内部路径、数据库结构等敏感信息

## 代码质量
- 新增功能必须有对应测试，尤其是边界情况和对抗性输入
- 修改现有代码前，先确认测试能通过；修改后测试仍必须通过
- 不要为单次使用的代码创建抽象

## Git
- Commit message 用英文，描述清楚做了什么、为什么
- 不要提交包含敏感信息的文件（.env、密钥文件）
- 2026-05-01: 当前项目规定：不能在 server 中安装扫描工具。server 保持最小依赖，扫描功能应作为独立组件或客户端实现。
